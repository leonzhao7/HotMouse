# 检测与防护验证

本技能用于验证题目给出的检测机制及其边界。Web 请求解析和 WAF 过滤由 filter-bypass 处理；不要把一次 HTTP 403 推断为终端或行为检测。

## 建立基线

记录样本、执行环境、权限、请求或输入、预期行为、实际行为，以及可观察的告警、日志、退出码和时间。先跑无害对照，确认观测渠道工作正常。

## 定位触发层

按输入解析、静态内容、运行时行为、网络策略和结果回传分层。每次只改变一个条件，比较同一观测渠道；无法观察的层标为未知。出现失败时先排除语法错误、依赖缺失、权限不足与目标宕机。

## 验证矩阵

| 维度 | 对照问题 |
|---|---|
| 内容 | 相同功能、不同数据时结果是否变化？ |
| 行为 | 相同输入、不同执行路径时结果是否变化？ |
| 环境 | 本地与题目容器的版本、架构和权限是否一致？ |
| 时间 | 阻断发生在提交、启动、执行中还是执行后？ |
| 证据 | 有无日志、告警、响应、退出码或可重复的副作用？ |

仅在授权的题目环境中使用最小样本复现；每组保留原样本、对照样本与结果。若无明确告警或日志，只能写“当前观测未见阻断”，不能宣称规避成功。

## 输出

检测点假设、对照实验、观测证据、复现条件和结论的适用范围。把题目要求的结果记录在当前题工作区；不要发送到外部地址。
